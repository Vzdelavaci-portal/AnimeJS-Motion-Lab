# Animated Navbar

## English

Animated Navbar is a modern responsive navigation component built with HTML, CSS, JavaScript and Anime.js.

The project demonstrates how motion can improve navigation by combining smooth transitions, magnetic hover effects, an animated active indicator, glassmorphism styling and a fully animated mobile menu.

Instead of using static navigation, every interaction provides subtle visual feedback while maintaining excellent usability.

## Features

* Responsive desktop and mobile navigation
* Glassmorphism navbar
* Animated active indicator
* Magnetic hover effect
* Smooth page scrolling
* Automatic active section detection
* Animated mobile navigation
* Morphing hamburger menu
* Scroll-aware navbar
* Animated hero intro
* Gradient text animation
* Floating background effects
* Keyboard accessibility
* Reduced motion support

## Main Features

### Animated Active Indicator

The active menu highlight smoothly moves between navigation items.

Instead of instantly jumping to another link, Anime.js animates the movement using spring easing, making navigation feel much more natural.

### Magnetic Hover

Desktop navigation items react to cursor movement.

The closer the cursor gets to the center of the button, the more the button gently follows the pointer before smoothly returning to its original position.

### Mobile Navigation

The mobile menu features:

* Morphing hamburger icon
* Animated panel expansion
* Staggered menu items
* Smooth closing animation
* Keyboard support
* Escape key closing

### Scroll Detection

The navigation automatically detects the current visible section.

As the user scrolls:

* the active menu item changes,
* the indicator moves,
* the navbar becomes smaller,
* shadows and blur effects are adjusted.

### Hero Animation

The landing section introduces:

* Glass navigation
* Animated logo
* Navigation links
* Project title
* Description
* CTA button

Everything appears in a carefully timed sequence using Anime.js timelines.

## Hlavní funkce

### Animovaný indikátor

Aktivní položka menu je zvýrazněna plynule se pohybujícím indikátorem.

Místo okamžité změny Anime.js animuje jeho přesun pomocí spring animace, díky čemuž působí přirozeněji.

### Magnetický hover

Položky desktopové navigace reagují na pohyb kurzoru.

Čím blíže je kurzor středu tlačítka, tím více jej tlačítko jemně následuje a po opuštění se plynule vrátí zpět.

### Mobilní navigace

Mobilní menu obsahuje:

* Animovanou hamburger ikonu
* Rozbalovací panel
* Postupný vstup položek
* Plynulé zavření
* Ovládání klávesnicí
* Zavření klávesou Escape

### Detekce scrollování

Navigace automaticky rozpoznává právě zobrazenou sekci.

Při scrollování:

* mění aktivní položku,
* přesouvá indikátor,
* zmenšuje navigaci,
* upravuje blur i stíny.

### Hero animace

Úvodní sekce postupně zobrazí:

* Glass navigaci
* Logo
* Navigační odkazy
* Nadpis projektu
* Popis
* CTA tlačítko

Celá sekvence je řízena pomocí Anime.js Timeline.
