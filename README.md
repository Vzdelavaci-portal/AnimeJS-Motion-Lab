# AnimeJS Motion Lab

## 🇬🇧 English

**AnimeJS Motion Lab** is a collection of modern web animations and interactive UI effects built with **Anime.js**.

This repository showcases creative animation techniques for modern websites and web applications. Each project is a standalone example focused on a specific animation or interaction, making it easy to explore, learn, and reuse in your own projects.

The goal of this collection is to demonstrate what's possible with Anime.js while keeping the code clean, organized, and easy to understand.

---

## ✨ Features

* Modern web animations
* Interactive UI effects
* Clean and reusable code
* Standalone examples
* Responsive designs
* HTML, CSS and JavaScript
* Powered by Anime.js

---

## 🛠 Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* Anime.js

---

## 🎯 Purpose

This repository is intended as a source of inspiration and practical examples for developers who want to create smooth, engaging and visually appealing web animations.

Each example is designed to be simple to understand, easy to customize and ready to use in real-world projects.

# 🇨🇿 Česky

**AnimeJS Motion Lab** je kolekce moderních webových animací a interaktivních UI efektů vytvořených pomocí knihovny **Anime.js**.

Repozitář obsahuje samostatné ukázky různých animačních technik pro moderní webové stránky a webové aplikace. Každý projekt se zaměřuje na jeden konkrétní efekt nebo interakci, takže je snadné pochopit jeho princip a případně jej použít ve vlastních projektech.

Cílem této kolekce je ukázat možnosti knihovny Anime.js pomocí přehledného, čistého a znovupoužitelného kódu.
