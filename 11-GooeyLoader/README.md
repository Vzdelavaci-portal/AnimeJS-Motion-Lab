# Gooey Loader

## English

Gooey Loader is a liquid loading animation built with HTML, CSS, JavaScript, SVG filters and Anime.js.

The project demonstrates how multiple animated blobs can merge, separate and move around a central point while a loading percentage progresses from 0 to 100%.

The gooey effect is created with an SVG filter, while Anime.js controls the motion, scaling, timing, progress and final completion animation.

## Features

- Liquid gooey animation
- Multiple animated blobs
- SVG gooey filter
- Animated loading percentage
- Progress bar
- Dynamic loading messages
- Blob merging animation
- Final completion pulse
- Replay button
- Ambient background animations
- Gradient heading animation
- Responsive design
- Reduced motion support

## Technologies

- HTML5
- CSS3
- JavaScript
- SVG Filters
- Anime.js
