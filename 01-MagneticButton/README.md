# Magnetic Button

## 🇬🇧 English

**Magnetic Button** is a modern interactive button built with **Anime.js v4**.

When the cursor enters the magnetic area, the button smoothly follows the mouse, creating a premium and engaging user experience. The text and glow move independently to enhance the illusion of a magnetic force, while a spring animation returns everything to the center after the cursor leaves.

This effect is perfect for landing pages, portfolios, SaaS websites, and modern user interfaces.

### ✨ Features

* 🧲 Magnetic cursor attraction
* ⚡ Smooth spring animations
* 💎 Glassmorphism design
* 🌈 Animated glow effect
* 🎯 Independent text movement
* 🖱️ Click animation
* 📱 Fully responsive
* 🚀 Built with Anime.js v4
* 🎨 Pure HTML, CSS and JavaScript

### 🛠 Technologies

* HTML5
* CSS3
* JavaScript (ES Modules)
* Anime.js v4


### ▶️ Run

Open the project using **Live Server** in Visual Studio Code.

Because Anime.js is loaded as an ES Module, opening the HTML file directly from the file system may not work correctly.

## 🇨🇿 Česky

**Magnetic Button** je moderní interaktivní tlačítko vytvořené pomocí **Anime.js v4**.

Jakmile kurzor vstoupí do magnetické oblasti, tlačítko se začne plynule přitahovat směrem ke kurzoru. Text i světelný efekt se pohybují nezávisle, díky čemuž animace působí přirozeně a profesionálně. Po opuštění oblasti se tlačítko pružně vrátí zpět do své výchozí pozice.

Efekt je ideální pro moderní webové stránky, landing pages, portfolia nebo jakékoliv výrazné CTA tlačítko.
